抖音收藏 · 一键同步书签生成器

这个书签是真正的「自动同步按钮」：在抖音收藏列表页（或单个视频页）点它，会用你的登录态把页面上所有视频提取出来，直接推送给站点的入库 Worker，自动建视频页 + 拉封面 + 部署。全程不用复制粘贴。

已预填当前部署地址；形如 https://xxxx.workers.dev（不要带结尾斜杠）。

📌 抖音收藏同步 推荐用「复制」+ 手动添加书签（见下方说明）；拖拽在 Chrome 会被剥掉 javascript: 协议而失效。

用法：
  1. 打开抖音收藏夹页面（douyin.com/user/self?showTab=favorite_collection）。
  2. 直接点收藏夹栏的「抖音收藏同步」即可——书签会先问站点「已收录哪些」，然后只滚动到本次新增的内容、自动跳过已收录的，不用手动滚，也不用每次都翻完全部列表。
  3. 页面顶部会显示「已扫描 N 条，自动跳过已收录内容，滚动到新内容…」，碰到已收录的边界就停，自动提取新内容并推送。
  4. 弹出「发现 N 条新内容，已推送」即成功，约 1 分钟后刷新站点即可看到。
前提：Worker 必须已部署且设置好 GH_TOKEN secret（持有 marginalia-site 仓库 contents 写权限的 fine-grained PAT）。否则推送会失败，书签会弹错误提示。
⚠ 安装方式（很重要）：Chrome / 新版 Edge 从网页拖拽 javascript: 书签时会静默剥掉协议，书签点下去完全没反应——你之前八成就是卡在这。正确做法：点「📋 复制书签代码」→ 在收藏夹栏右键 → 添加网页 → 名称随意、网址栏粘贴刚才复制的内容。Firefox / Safari 可直接拖拽。

注：自动滚动期间不要手动滚动或切换标签页，以免打断加载。若抖音页面启用了严格 CSP 拦截跨域请求，书签会提示失败——此时改用「抖音封面导出」书签导出 covers.txt 发给我跑脚本即可（半自动兜底）。

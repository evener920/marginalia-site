抖音视频抓取 · 书签生成器

把下面这个按钮 拖到浏览器收藏夹栏，就得到一个「一键抓取」书签：在抖音单个视频页点它，会用你的登录态把视频直链下载到本机（文件名即视频 ID），并附带一份 <ID>.json 元数据（标题/封面/链接），剪贴板也会复制一份。

📥 抖音视频抓取

为什么需要这个书签？

抖音视频本体服务端拿不到（登录态 + 反爬），所以只能用你浏览器里的登录态在播放页把真实 mp4 直链下到本机。这一步绕不开——之后转写、入库都自动。

完整流程：
  1. 在抖音打开一条视频（不是收藏列表），点开播放让它加载。
  2. 点收藏夹栏的「抖音视频抓取」→ 浏览器下载 <视频ID>.mp4 与 <视频ID>.json，并复制 ID|标题|封面。
  3. 把这两个文件放进项目 marginalia/_inbox/ 目录。
  4. 告诉我「跑 ingest」，我执行 tools/ingest_inbox.py：抽音频 → Whisper 转写 → 生成/更新视频页 → 提交上线。

注：抓的是抖音临时 CDN 直链，通常有时效，请尽快转入 _inbox 处理。个别视频若页面未暴露直链，书签会提示，可改用「在抖音打开 → 右键视频 → 另存为」手动下载，再丢进 _inbox。

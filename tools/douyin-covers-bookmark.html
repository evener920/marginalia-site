抖音收藏封面导出 · 生成器

把抖音收藏页所有视频的 视频ID|封面URL 导出成 covers.txt，发给我即可一次性补全 marginalia 缺失的 102 个封面。

💡 推荐方案：用户脚本按钮版（彻底避免「点击没反应」）

Chrome / Edge 从网页安装 javascript: 书签时会静默剥掉协议前缀，导致点击毫无反应——你之前就卡在这。改用浏览器扩展 Tampermonkey / Violentmonkey 安装下面的用户脚本，它会在抖音页面右下角常驻一个「导出封面」按钮，点一下就导出，永久有效、不怕被剥。

  1. Chrome 网上应用店搜 Tampermonkey 安装（已装则跳过）。
  2. 点下面「📥 下载用户脚本」用 Tampermonkey 打开即自动提示安装；或点「📋 复制用户脚本」后在 Tampermonkey「新建脚本」里粘贴保存。
  3. 打开抖音收藏页（douyin.com/user/self?showTab=favorite_collection），滚动到底让卡片加载完，点右下角「导出封面」按钮 → 下载 covers.txt。
  4. 把 covers.txt 发给我即可。

📥 下载用户脚本

备选：书签版（Firefox / Safari 可直接拖拽；Chrome 需复制粘贴）

把下面按钮 拖到收藏夹栏，或点「📋 复制书签代码」后手动添加：

📌 抖音封面导出 Chrome 拖拽会剥掉 javascript: 协议；请点「复制书签代码」→ 收藏夹栏右键 → 添加网页 → 网址栏粘贴。

⚠ 安装方式（Chrome / Edge 必看）：从网页拖拽 javascript: 书签时会静默剥掉协议前缀，书签点下去完全没反应——你刚才点没反应就是这原因。正确做法：点「📋 复制书签代码」→ 收藏夹栏右键 → 添加网页 → 名称随意、网址栏粘贴。Firefox / Safari 可直接拖拽。
用法（书签版）：
  1. 打开抖音收藏夹页面 douyin.com/user/self?showTab=favorite_collection。
  2. 滚动到底部，让所有视频卡片都加载出来。
  3. 点击收藏夹栏里的「抖音封面导出」书签 → 下载 covers.txt 并弹出「已导出 N 条」。
  4. 把 covers.txt 发给我，我跑 fetch_covers.py 一次性补全封面。

注：封面地址多为临时 CDN，脚本会一并下载到本地 assets/img/covers/ 再引用，避免热链失效。若导出 0 条，通常是页面还没加载出视频卡片，先滚动到底再点一次即可。

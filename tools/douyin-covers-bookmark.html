抖音收藏封面导出 · 书签生成器

把下面这个按钮 拖到浏览器收藏夹栏（或右键「添加网页」），就得到一个一键导出书签：

📌 抖音封面导出 推荐用「复制」+ 手动添加书签（见下方说明）；拖拽在 Chrome 会被剥掉 javascript: 协议而失效。

⚠ 安装方式（很重要）：Chrome / 新版 Edge 从网页拖拽 javascript: 书签时会静默剥掉协议前缀，书签点下去完全没反应——你刚才大概率卡在这。正确做法：点「📋 复制书签代码」→ 在收藏夹栏右键 → 添加网页 → 名称随意、网址栏粘贴刚才复制的内容。Firefox / Safari 可直接拖拽。
用法：
  1. 先打开抖音收藏夹页面 douyin.com/user/self?showTab=favorite_collection。
  2. 把页面滚动到底部，让所有视频卡片都加载出来（否则只导出视口内的）。
  3. 点击收藏夹栏里的「抖音封面导出」书签。
  4. 浏览器会下载一个 covers.txt，并弹出「已导出 N 条」提示；内容是每行 视频ID|封面URL。
  5. 把 covers.txt 发给我，我跑 fetch_covers.py 一次性补全封面。

注：抖音图片地址多为临时 CDN，脚本会一并下载到本地 assets/img/covers/ 再引用，避免热链失效。若导出 0 条，通常是页面还没加载出视频卡片，先滚动到底再点一次即可。
